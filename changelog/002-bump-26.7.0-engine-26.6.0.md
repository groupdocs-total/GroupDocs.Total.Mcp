# Bump to MCP 26.7.0 / engine GroupDocs.Total 26.6.0

## What changed

- **MCP version** `26.5.0` → `26.7.0` (CalVer YY.M.N). Bumped in
  `build/dependencies.props` (`<GroupDocsTotalMcp>`), both `version` fields of
  `.mcp/server.json`, and the `@version` pins in `README.md` and `llms.txt`.
- **Engine bundle** `GroupDocs.Total` `26.4.0` → `26.6.0` (single metapackage,
  transitively pulling all 14 GroupDocs product engines). Prose reference in
  `AGENTS.md` updated accordingly.
- No tool-surface change: still **38 tools across 10 product domains** + the two
  cross-product tools. Tool sources are unchanged vendored copies.

## Why

Routine CalVer + engine refresh to pick up GroupDocs.Total 26.6.0 fixes across
the bundled engines.

## Migration / impact

Drop-in. Same tool catalog, same environment variables
(`GROUPDOCS_MCP_STORAGE_PATH`, `GROUPDOCS_MCP_OUTPUT_PATH`,
`GROUPDOCS_LICENSE_PATH`), same `groupdocs-total-mcp` command name.

Known follow-up (carried from 001): the 20 framework-vendored tools still lack
Pitfall #18 try/catch + descriptive `FormatException` wrappers, and there is no
shared `Tools/ToolError.cs`. Distribution note: the packed nupkg exceeds
NuGet.org's 250 MB hard limit because the bundle includes GroupDocs.Parser's
~234 MiB of embedded ONNX models — Total is Docker-first for distribution
(pitfall Z).
